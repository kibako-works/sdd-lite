# 0003. 案内の判断基準の正本を guide.md に置き、スキルのディレクトリの外は読まない

- Status: Superseded by 0006
- 日付: 2026-10-19
- 関連: docs/design/2026-10-initial-release.md

## Context（背景）
- `/sdd:ask` は、判断基準（全体の流れ・規模の判定・コマンド一覧・現在地の判定）を読んで案内する。判断基準を README とスキルの両方に書くと、内容がずれていく。
- 判断基準を README に置き、スキルから読む方法を検証したところ、次のことが分かった。
  - `${CLAUDE_SKILL_DIR}` には、シンボリックリンクを解決しないパスが入る。`${CLAUDE_SKILL_DIR}/../../README.md` を Read ツールで読むと、Read は `..` をリンクをたどらずに畳むため、読み込みに失敗する。
  - SKILL.md のシェル展開（`` !`cat ...` ``）で外部のファイルを読むと、作業ディレクトリの外を読むことになり、既定の権限で止まる。利用者ごとに許可の設定が必要になる。

## Decision（決定）
- `/sdd:ask` の判断基準の正本は `plugins/sdd/skills/ask/guide.md` に置くこと。
- `ask` は `${CLAUDE_SKILL_DIR}/guide.md` を Read ツールで読むこと。スキルから `..` を含むパスやシェル展開で、スキルのディレクトリの外を読まないこと。
- README には人間向けの内容（背景・前提・導入・注意点・外す条件と手順）と guide.md へのリンクだけを置き、guide.md の表や手順を重複させないこと。
- 各スキルの実行手順の正本はそれぞれの SKILL.md とし、guide.md には使い分けと流れを書くこと。

## Consequences（結果）
- 判断基準が 1 か所にまとまり、README との食い違いが起きない。
- `ask` を外すときは、guide.md の内容を README などへ移す必要がある。
- 純正の機能で、スキルのディレクトリの外を安全に読めるようになったら、この決定を見直す。

## 検証方法（任意）
- `` grep -rnE '\.\./|!`' plugins/ `` の結果が 0 件であること。
