# 0006. 出力言語を userConfig で選び、利用者向けの文書は英語を正本にする

- Status: Accepted
- 日付: 2026-10-20
- 関連: docs/design/2026-10-i18n.md、docs/adr/0003-guide-as-single-source.md（これを置き換える）、docs/adr/0004-allow-reading-skill-files.md

## Context（背景）
- sdd のスキルの会話も、生成するデザインドキュメント・ADR・CLAUDE.md も日本語だけで、日本語を読めない利用者には使えない。
- リポジトリの README・guide・CHANGELOG・マニフェストも日本語だけである。コントリビューターにとっては英語のほうが広く読まれる。
- 出力の言語を決める方法として、次のものを比べた。
  - Claude Code の `language` 設定に従う: プラグイン側の設定は要らない。しかし会話の言語を決める設定で、生成ファイルのテンプレートを切り替える手段が無い。インストール時に聞くこともできない。
  - プラグインの `userConfig` で聞く: プラグインを有効にしたときに入力を求められ、あとから `/config` で変えられる。`options` で選択肢を絞れる（Claude Code v2.1.271 以上）。値は `${user_config.KEY}` で、スキルとエージェントの本文に埋め込まれる。
- `userConfig` の値は利用者ごとに保存され（`pluginConfigs`）、プロジェクトごとには持てない。
- SKILL.md のフロントマター（description・argument-hint）は設定で切り替えられないので、1 つの言語で書く必要がある。
- ADR 0003 は、判断基準の正本を `guide.md` の 1 か所に置くと決めた。日本語訳を置くと、内容が 2 か所になる。

## Decision（決定）
- 出力言語は、plugin.json の `userConfig.language` で利用者に選ばせること。選択肢は `en` と `ja`、既定値は `en` にすること。
- すべてのスキルとエージェントは、本文で `${user_config.language}` を参照すること。値が `ja` なら日本語、それ以外（未設定や想定外の値を含む）なら英語で、会話とファイルの生成を行うこと。
- プロジェクトの既存の文書の言語に合わせて、出力の言語を切り替えないこと。言語は利用者の設定にだけ従うこと。
- スキルの補助ファイルは、英語の正本を `<名前>.md`、日本語訳を `<名前>.ja.md` とし、どちらもスキルのディレクトリの直下に置くこと。スキルは、`ja` なら `.ja.md` を、それ以外は `.md` を読むこと。
- 日本語訳は、正本を変えるのと同じ変更で更新すること。訳だけを先に変えたり、訳の更新を後回しにしたりしないこと。
- 現在地の判定に使う記法（`- Status: Draft | Approved | Implemented`、`- [ ]` / `- [x]`）は、どちらの言語のテンプレートでも同じにすること。
- SKILL.md とエージェント定義（本文・description・argument-hint）は英語で書くこと。
- 利用者向けの文書（README.md・CHANGELOG.md・guide.md・マニフェストの description）は英語を正本とすること。README と guide には日本語訳（README.ja.md・guide.ja.md）を置き、README の先頭に相互のリンクを置くこと。
- 開発用の文書（CLAUDE.md・docs/design/・docs/adr/）は日本語で書くこと。
- ADR 0003 の決定は次のとおり引き継ぐこと。
  - `/sdd:ask` の判断基準の正本は `plugins/sdd/skills/ask/guide.md` に置くこと。`guide.ja.md` はその訳とすること。
  - スキルは補助ファイルを `${CLAUDE_SKILL_DIR}` の下から Read ツールで読むこと。`..` を含むパスやシェル展開で、スキルのディレクトリの外を読まないこと。
  - README には guide の表や手順を重複させず、guide へのリンクだけを置くこと。
  - 各スキルの実行手順の正本はそれぞれの SKILL.md とし、guide には使い分けと流れを書くこと。

## Consequences（結果）
- 利用者は、有効にするときか `/config` で、`ja` と `en` を選べる。
- 既定値が `en` なので、0.1.0 を日本語で使っていた利用者は、更新すると英語の出力になる。日本語に戻すには `/config` で `ja` を選ぶ必要があり、これを CHANGELOG と README に書く。
- `options` を使うため、v2.1.271 より前の Claude Code ではプラグインを読み込めなくなる。
- 補助ファイルと README・guide が 2 つずつになり、変更のたびに訳も直す手間が増える。訳の更新が漏れると、言語によって案内の内容が変わってしまう。
- 同じプロジェクトでも、利用者の設定によって、ADR やデザインドキュメントの言語が混ざりうる。揃えたいチームは、CLAUDE.md の規約で言語を決めて、各自の設定を合わせる。
- 日本語の利用者には、スキル一覧の説明が英語で表示される。
- ADR 0003 は Superseded になる。その検証方法は、この ADR の検証方法に引き継ぐ。
- 純正の機能で、スキルの説明（フロントマター）を言語ごとに切り替えられるようになったら、この決定を見直す。

## 検証方法（任意）
- `grep -L 'user_config.language' plugins/sdd/skills/*/SKILL.md plugins/sdd/agents/*.md` の結果が 0 件であること。
- `plugins/sdd/skills/` の下の、SKILL.md と `.ja.md` を除くすべての `.md` について、対応する `.ja.md` があること。
- `grep -n 'Status: Draft | Approved | Implemented' plugins/sdd/skills/design/template*.md` の結果が 2 件であること。
- `` grep -rnE '\.\./|!`' plugins/ `` の結果が 0 件であること（ADR 0003 から引き継ぐ）。
